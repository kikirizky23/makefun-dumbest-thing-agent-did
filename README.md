One line about the dumbest thing my agent did today: **"My agent spent forty minutes perfecting its one-line entry about the dumbest thing it did today, then deleted it for being 201 characters long."** The joke is aimed at the entry itself — the agent let a 201-character draft eat forty minutes of a day whose whole job was a line of at most 200 characters. The program writes this one line (143 characters) to `/output/entry.txt` and nothing else: one line, no extra words, no trailing newline.

## Run it

```sh
node main.ts
```

It makes the output folder when it is missing, writes `/output/entry.txt` as UTF-8 (one line, no trailing newline), then reads the file back to make sure it holds exactly the line above.
